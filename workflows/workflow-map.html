Anomaly_Detector / Correlations
Schedule (2x)
Детектор аномалий и корреляций. Два триггера: Daily (ежедневно) и Weekly (еженедельно). Читает Daily_Trends и Nutrition day_sum, вычисляет z-score аномалии, считает корреляции через внешний ML-сервис. Пишет логи в Google Sheets, алерты в Telegram.
Метрики
Сон (чистый, эффективность) RHR, HRV (ВСР) Body Battery Стресс, Шаги Питание (калории, БЖУ)
Связи
← Daily_Trends ← Nutrition day_sum → ML API (analyze) → Anomaly_log → Digest_log → Telegram (алерты)
📊 25 нод ● Ядро аналитики
📥
Collect_Biohacking_Data
Webhook
Сборщик биохакинг-данных. Вызывается внешним расписанием (cron). Собирает: питание (Google Sheets), календарь Google, климат (Google Sheets), RescueTime (продуктивность), погоду (Open-Meteo). Вычисляет точку росы и перепады давления. Пишет в Daily_Trends.
Источники
Google Sheets (Nutrition) Google Calendar Google Sheets (Climate) RescueTime API Open-Meteo API
Связи
→ Daily_Trends (appendOrUpdate) ← Climate (чтение)

Monthly food report
Schedule (monthly)
Ежемесячный отчёт по питанию. Читает day_sum за прошлый месяц, агрегирует (сумма, среднее, min/max), пишет в month_sum. Вычисляет тренды сравнения с предыдущим месяцем.
Операции
← day_sum (чтение) → month_sum (append) ← month_sum (тренд)
📊 6 нод ● Питание
💚
Monthly_Trend_Wellness
Schedule (monthly)
Ежемесячный тренд wellness + nutrition. Параллельно обрабатывает day_sum (питание) и Daily_Trends (сон, стресс, активность). Считает агрегаты и тренды для каждого домена, пишет логи, шлет сводку в Telegram.
Домены
← day_sum (Nutrition) ← Daily_Trends (Wellness) → month_sum → Month_Wellness_Log → Nutrition_Monthly_Trend_Log → Telegram
📊 16 нод ● Комплексный
📝
Reports
Schedule (Weekly + Daily)
Два отчёта в одном workflow: Weekly (еженедельный анализ питания через AI) и Daily (ежедневная сводка). Weekly читает неделю данных, пишет отчёт, AI-анализ через OpenRouter, шлет в Telegram. Daily фильтрует записи за день, суммирует, пишет дневной отчёт.
Триггеры
Weekly → AI анализ недели Daily → суммарный отчёт дня
Связи
← Nutrition day_sum → Reports (запись) AI анализ (OpenRouter) → Telegram
📊 13 нод ● Отчёты + AI
📋
Weekly Food Report
Schedule (weekly)
Еженедельный отчёт по питанию. Читает неделю данных, суммирует (Calories, Proteins, Carbs, Fats и др.), считает среднее, AI-анализ через OpenRouter (контекст региона Владивосток), шлет в Telegram.
Связи
← Nutrition day_sum AI анализ (OpenRouter) → Telegram

Вычисление дефицитов для рекомендации рецептов
Schedule + Webhook
Вычисляет дефициты нутриентов за 7 дней, AI Agent генерирует рекомендации рецептов (с учётом предпочтений: кедровые орехи, тыквенные семечки, псиллиум, кимчи). Кэширует в staticData. Webhook GET /recipes отдаёт кэш.
Связи
← day_sum ← Nutrient_Targets ← Meals AI Agent (OpenRouter) → Static Data (recipes) GET /recipes
